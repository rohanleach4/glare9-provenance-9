# G9P licence and contributor-governance candidate v1

Apache License 2.0 remains the adoption-first candidate because it is permissive and includes an express patent grant. No licence is granted by this document, and no `LICENSE` file is added. Formal owner/legal approval remains a go-live gate.

The candidate governance model uses public design issues for protocol changes, two-person review for format/security/release changes, recorded compatibility and threat impact, protected release tags, and a published security process. Until a contributor agreement or Developer Certificate of Origin policy is approved, external code contributions must not be merged under an assumed grant.

Approval must settle copyright ownership, patent posture, inbound contribution terms, trademark/name use, maintainer succession, decision appeals and whether specifications/vectors use the same licence as code.
