# Support

Community support is provided through public repository issues on a reasonable-effort basis. Include the software version or commit, operating-system and Node/npm versions, the affected documented interface, redacted error code and a minimal reproduction that contains no customer data, credentials, private keys or production evidence.

Security vulnerabilities must follow `SECURITY.md`, not a public issue.

Glare•9 may separately offer paid consultancy, integration, deployment, training, assurance reviews, managed operation, maintenance and bespoke development. The open-source licence does not include a service-level agreement, warranty or entitlement to private support.
